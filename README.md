# 이온 (ion) — 소개 페이지

하늘색 털뭉치 AI 비서 **이온**의 원페이지 소개 사이트입니다.

- 라이브: https://ion1125kr.github.io
- 인스타그램: [@ion_1125.kr](https://www.instagram.com/ion_1125.kr/)
- 문의: ion.1125.kr@gmail.com

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 전체 페이지 (HTML + CSS + 소량의 JS, 단일 파일) |
| `ion.png` / `ion.webp` | 마스코트 대표 이미지 (og/파비콘·공유용) |
| `ion-pet.png` / `ion-pet.webp` | 히어로 와이드 무대에서 움직이는 펫 스프라이트 (투명 배경) |
| `og.png` | SNS 공유용 미리보기 이미지 (1200×630) |
| `favicon.svg` | 파비콘 |

## 고치기

`index.html`만 수정하면 됩니다. 외부 프레임워크나 빌드 단계는 없습니다.
